Variante formelle (MDP / POMDP)

  • États : s_t = (v_t, m_t, r_t) avec variables vitales, mémoire, risque.
  • Observations : o_t issues des capteurs, logs, métriques.
  • Actions : a_t (outils, messages, déploiements, contrôles).
  • Transition : P(s_{t+1} | s_t, a_t) injecte l’aléa réel.
  • Récompense : R(s_t, a_t) pondère survie, stabilité, coût, confiance.
  • Contraintes : sûreté hard (non-violation) + budgets (soft).
